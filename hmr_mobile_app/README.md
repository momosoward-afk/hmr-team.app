# 📱 تطبيق جوال منصة HMR للتسويق (Flutter Wrapper)

مرحباً بك! هذا المجلد يحتوي على مشروع **Flutter** مستقل ومتكامل لتغليف موقع منصة HMR وتحويله إلى تطبيق جوال ذكي لنظام **Android** (بصيغة APK) ونظام **iOS**.

---

## ✨ مميزات التطبيق
1. **أداء سلس ومتجاوب:** يعرض الموقع مباشرة دون إظهار أشرطة التصفح المزعجة.
2. **شاشة إقلاع (Splash Screen) مميزة:** تظهر للمستخدم أثناء تهيئة وتحميل النظام.
3. **معالجة انقطاع الإنترنت:** إذا انقطع الاتصال بالإنترنت، يظهر التطبيق شاشة تنبيه احترافية باللون الداكن مع زر "إعادة المحاولة" بدلاً من شاشة المتصفح البيضاء.
4. **دعم زر الرجوع:** يدعم زر الرجوع في هواتف أندرويد للتنقل داخل صفحات الموقع بدلاً من إغلاق التطبيق فجأة.

---

## 🛠️ طرق بناء وتوليد ملف التطبيق (APK)

لقد قمنا بتجهيز طريقتين ميسرتين للحصول على التطبيق:

### 🚀 الطريقة الأولى: البناء التلقائي عبر GitHub (بدون تثبيت أي برامج) - *موصى بها*
لقد أعددنا لك ملف بناء تلقائي في المسار `.github/workflows/build_apk.yml` بحيث يقوم خادم GitHub ببناء التطبيق لك مجاناً.
1. قم برفع هذا المشروع كاملاً على حسابك في **GitHub** في مستودع (Repository) خاص أو عام.
2. بمجرد رفع المشروع، توجه إلى تبويب **Actions** في صفحة مستودعك على GitHub.
3. ستجد عمل سيرفر يسمى **Build Android APK** قد بدأ بالعمل تلقائياً.
4. بعد اكتمال البناء (يستغرق حوالي 3 إلى 5 دقائق)، اضغط على التشغيل وقم بتحميل ملف الـ APK المسمى **HMR_Network_App** من أسفل الصفحة.

---

### 💻 الطريقة الثانية: البناء المحلي (إذا كان لديك بيئة Flutter)
إذا كنت تمتلك برنامج Flutter SDK مثبتاً على جهازك:
1. افتح موجه الأوامر (Terminal) في هذا المجلد `hmr_mobile_app`.
2. قم بتنزيل المكتبات عبر الأمر:
   ```bash
   flutter pub get
   ```
3. قم ببناء ملف الـ APK بنسخة الإنتاج عبر الأمر:
   ```bash
   flutter build apk --release
   ```
4. ستجد ملف الـ APK الجاهز في المسار التالي داخل المشروع:
   `build/app/outputs/flutter-apk/app-release.apk`

---

### ☁️ الطريقة الثالثة: البناء السحابي عبر Codemagic
1. توجه إلى **[Codemagic.io](https://codemagic.io/)** وأنشئ حساباً مجانياً.
2. اربط حساب GitHub الخاص بك واختر هذا المشروع.
3. حدد نوع المشروع كـ **Flutter App**، ثم اختر نظام التشغيل **Android**.
4. اضغط على **Start Build**، وعند الانتهاء سيتم إرسال رابط تحميل ملف الـ APK الجاهز إلى بريدك الإلكتروني!
